# Seating Planner

A seating plan tool for teachers. It runs entirely in the browser: class lists and
seating plans are stored on your own computer and are never uploaded.

- Build a desk layout for each class
- Drag students into seats, or shuffle them
- Save plans and reload earlier ones
- Present view, drawn from the students' side of the room
- Print one or two classes per portrait page (or save as PDF)
- Backup / Restore to move your data between computers

Open `index.html`, or visit the GitHub Pages site for this repository.
